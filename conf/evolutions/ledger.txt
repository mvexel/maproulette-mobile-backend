# Evolution ledger for conf/evolutions/default/.
#
# Play applies N.sql from 1 upward and stops at the first missing number, so the fork
# and upstream share one gapless sequence. This file says who owns each number above the
# upstream base. EvolutionLedgerSpec checks it against the files; the procedure for
# claiming a number and for upstream syncs is in docs/upstream-sync.md.
#
# base <n>                 1..n are upstream's own files, unchanged.
# synced <commit> <n>      Last upstream sync: upstream commit and its highest evolution.
# <n> fork <note>          A fork migration.
# <n> upstream:<m> <note>  Upstream's m.sql, copied to n because the fork already used m.
# <n> reserved <note>      Claimed by an open PR. No file yet. The PR that adds n.sql
#                          changes the row to "fork".
